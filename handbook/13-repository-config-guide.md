# Repository and configuration guide

This page explains the files and directories around the Python and Dart source
maps. Generated dependency/build internals are described by category rather
than file-by-file because their contents belong to Flutter, Gradle, Python, or
Git—not to SpeakFlow's application design.

## Repository root

- **`README.md`** — Installation, daily startup, feature summary, and common setup
  failures.

- **`handbook/`** — Architecture, file maps, runtime flows, and maintenance guides.

- **`backend/`** — FastAPI application, PLP engine, migrations, ML runtimes, tools,
  and tests.

- **`frontend/`** — Flutter application, Android host project, assets, and widget tests.

- **`admin-dashboard/`** — React/Vite operations client, static assets, npm lockfile,
  lint configuration, and local backend proxy.

- **`compose.yaml`** — PostgreSQL 16 + pgvector service, health check, port, and durable
  named volume.

- **`.env.example`** — Safe template for provider, database, PLP, Ollama, and model
  settings.

- **`.env`** — Ignored machine-specific secrets/settings; never document or commit its
  values.

- **`.gitignore`** — Excludes secrets, model assets, raw data, environments, caches, and
  build output.

- **`.github/workflows/quality.yml`** — Pull-request and main-branch validation for
  the backend, Flutter app, dashboard, and Alembic metadata.

## Environment variables

`.env.example` groups the external/runtime contract:

- **`GROQ_*`** — API key and models for general, pronunciation, and PLP text generation.

- **`PRONUNCIATION_COACH_PROVIDER`** — Selects configured coaching provider policy.

- **`NEWSAPI_KEY`** — Enables live news; optional for other features.

- **`DATABASE_URL`** — SQLAlchemy/psycopg connection used by app, tests, migrations, and
  tools.

- **`POSTGRES_*`** — Docker Compose database/user/password/host-port values.

- **`PLP_DATA_ROOT`** — Local non-database PLP operational data root.

- **`OLLAMA_*`** — Local Ollama base URL and curriculum embedding model.

- **`SPEAKFLOW_HOST` / `SPEAKFLOW_PORT`** — FastAPI listener; defaults to loopback
  port 8000.

The release Flutter URLs are Dart compile-time definitions, not `.env` values.
See `ApiConfig` and the README deployment instructions.

The dashboard has no environment-variable API origin today. Its source uses
relative `/api/auth` and `/admin` URLs, and `vite.config.js` proxies those paths
to `127.0.0.1:8000` only during `npm run dev`.

Compose publishes PostgreSQL on `127.0.0.1` rather than all host interfaces.

## Backend support directories

- **`backend/migrations/`** — Alembic environment, template, and ordered schema
  revisions.

- **`backend/tests/`** — Backend unit, contract, architecture, characterization,
  and integration tests, grouped by application or feature ownership. Learning
  plan contracts, generation, weekly missions, and support fixtures have
  dedicated subpackages; runtime fixtures live beside the suites that consume
  them.

- **`backend/requirements-dev.txt`** — Pinned backend static-analysis tooling.

- **`backend/tools/`** — Thin supported audit command entrypoints and their README.

- **`backend/resources/gector/`** — Small tracked GECToR license/vocabulary resources.

- **`backend/pretrained_models/`** — Ignored managed pronunciation weights installed by
  setup.

- **`backend/.models/`** — Ignored grammar, WhisperX, TTS, NLTK, manifest, and
  curriculum assets.

Python `__pycache__/` and `.pyc` files are interpreter-generated caches. They do
not define modules and may contain stale bytecode after a source file is moved;
they must remain ignored and can be removed safely when the process is stopped.

## Flutter package files

- **`frontend/pubspec.yaml`** — Dart SDK range, package dependencies, assets, and local
  font families.

- **`frontend/pubspec.lock`** — Exact resolved dependency versions; commit for
  reproducible application builds.

- **`frontend/analysis_options.yaml`** — Enables the recommended Flutter lint set.

- **`frontend/.metadata`** — Flutter tool project metadata used for upgrade/migration
  behavior.

- **`frontend/test/`** — Widget, model, adapter, architecture, and source-size
  tests grouped under `app/`, `architecture/`, `core/`, and feature directories
  that mirror `frontend/lib` ownership.

- **`frontend/assets/`** — Tracked runtime fonts, font licenses, and test/mock plan
  fixture.

- **`frontend/android/`** — Native Android host, Gradle wrapper/configuration,
  manifests, resources, and Kotlin activity.

`.flutter-plugins-dependencies`, `.dart_tool/`, `build/`, and platform build
caches are generated by Flutter/Gradle. Do not edit or document their individual
internal files; regenerate them with `flutter pub get` or a clean build.

## Flutter dependencies

The direct package choices have focused roles:

- **`go_router`** — declarative routes, auth redirect, shell navigation, full-screen
  pushes.

- **`flutter_riverpod`** — dependency-provider composition and controller injection.

- **`http`** — REST and multipart transport inside `ApiClient`/feature adapters.

- **`web_socket_channel`** — authenticated live roleplay transport.

- **`record`** — microphone recording.

- **`audioplayers`** — TTS and recorded/reply playback.

- **`permission_handler`** — runtime microphone permission.

- **`path_provider`** — app documents directory for local stores/preferences.

- **`flutter_secure_storage`** — platform-protected session storage support.

- **`flutter_animate`** — intentional presentation animation helpers.

## Assets

- `assets/fonts/Inter.ttf` and italic variant: primary interface typography.
- `assets/fonts/Outfit.ttf`: selected headings/feature typography.
- `assets/fonts/Cairo.ttf`: Arabic-capable display.
- `assets/fonts/SourceCodePro.ttf`: phonetic/code-like aligned content.
- corresponding `*-OFL.txt` files: font licenses.
- `test/fixtures/plp_plan.json`: deterministic test-only plan fixture; it is not
  declared in `pubspec.yaml` or bundled into production builds.

Runtime Flutter assets must be declared in `pubspec.yaml`. Test fixtures remain
under `test/`; large ML weights belong to the backend model bundle.

## Android host project

- **`android/settings.gradle.kts`** — Plugin repositories, Flutter plugin loader, and
  app module inclusion.

- **`android/build.gradle.kts`** — Root Android build output and clean-task
  configuration.

- **`android/app/build.gradle.kts`** — Application ID, SDK/JVM settings, Flutter plugin,
  and optional secure release signing.

- **`android/gradle.properties`** — Gradle/JVM and AndroidX build properties.

- **`android/gradle/wrapper/*`** — Pinned Gradle launcher version and wrapper
  binaries/scripts.

- **`android/app/src/main/AndroidManifest.xml`** — Internet/audio permissions,
  app/activity metadata, release cleartext prohibition.

- **`android/app/src/debug/AndroidManifest.xml`** — Debug-only networking policy needed
  for local HTTP development.

- **`android/app/src/profile/AndroidManifest.xml`** — Profile-build manifest overlay.

- **`android/app/src/main/kotlin/.../MainActivity.kt`** — Minimal Flutter Android
  activity host.

- **`android/app/src/main/res/`** — Launcher icons, launch background, and Android
  themes.

`android/local.properties`, `.gradle/`, `.kotlin/`, `key.properties`, and
keystore files are machine-generated or secret. They must remain uncommitted.
Release signing is configured only when all required `key.properties` values
exist; release traffic also requires HTTPS/WSS at the Dart layer.

## Operations dashboard package files

- **`admin-dashboard/package.json`** — React/Vite dependencies and dev, test, lint,
  build, and preview scripts.
- **`admin-dashboard/package-lock.json`** — Exact npm dependency resolution.
- **`admin-dashboard/vite.config.js`** — React plugin and development-only auth/admin
  proxies.
- **`admin-dashboard/.oxlintrc.json`** — React hooks/export lint policy.
- **`admin-dashboard/src/`** — Authenticated transport, login, dashboard composition,
  focused panels, and CSS.
- **`admin-dashboard/test/`** — Node tests for dashboard authentication and transport.
- **`admin-dashboard/public/`** — Static icons/favicon copied into builds.

`node_modules/` and `dist/` are generated and ignored. Use `npm ci` to restore
dependencies and `npm run build` to regenerate `dist/`. FastAPI does not serve
the built files; a production static host must use HTTPS and share a
reverse-proxied origin with `/api/auth` and `/admin`.

- Change dashboard setup, endpoint, and build details in
  `admin-dashboard/README.md` and `handbook/14-admin-dashboard.md`.

  model bundle contract changes.
